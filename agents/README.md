# Общий контекст агентов RunneOS

Навык всех агентов: [runneos](../.agents/skills/runneos/SKILL.md). Единственный редактируемый источник находится в репозитории; установленным клиентам он доступен через символические ссылки.

Подключение на рабочем месте:

```bash
bash scripts/install-agent-skill.sh
```

Скрипт подключает навык в `~/.agents/skills`, `~/.codex/skills` и `~/.claude/skills`, не заменяя чужие файлы. OpenCode обнаруживает общий каталог `~/.agents/skills` согласно [его документации](https://opencode.ai/docs/skills/). Клиенты без поддержки навыков читают `AGENTS.md`; дополнительные точки входа — `CLAUDE.md` и `GEMINI.md`.

В Codex можно явно вызвать `$runneos`; в остальных клиентах — навык с именем `runneos`. Новая сессия перечитывает каталог доступных навыков. Обновлять нужно исходник в репозитории, а не создавать независимые копии.

На текущей машине OpenCode разрешено загружать только навык `runneos` без отдельного запроса (`permission.skill.runneos=allow`); прежний режим остальных навыков сохранён.
